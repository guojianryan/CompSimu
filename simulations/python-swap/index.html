Swapping two variables in Python

Watch values move between memory boxes as Python executes a temp-variable swap one line at a time — and see exactly what goes wrong without it.

Python Beginner Variables · Assignment ~5 min
Why swapping needs care

Assignment overwrites

You want a to hold b’s value and b to hold a’s value. But Python runs one statement at a time, and the moment you write a = b, the original value of a is replaced.

So a correct swap must keep a copy of one value before it gets overwritten. That’s the job of a third variable, usually called temp.

TipBefore you overwrite a variable, ask: “do I still need its old value?”

Watch out

Common mistakes to avoid

Even with a temp variable, the order of the three lines matters.

Saving the wrong value 
temp = a
b = a      # should be a = b
a = temp

Both end up as 5. Whatever you save in temp, the next line must overwrite that same variable.

Saving too late 
a = b
temp = a   # 5 is already gone
b = temp

The copy must happen before the overwrite. Here temp captures 10, not 5.

The pattern to remember 
temp = a   # 1. save a
a = b      # 2. overwrite a
b = temp   # 3. restore into b

Each line’s right side is the previous line’s left side: a → temp, b → a, temp → b.
