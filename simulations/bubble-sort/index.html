Bubble sort

Compare each pair of neighbours. Swap if they’re out of order. After each pass, the next-largest value settles at the end.

Algorithms Beginner Sorting ~7 min
The idea

Largest values “bubble” up

Bubble sort repeatedly walks the list, swapping adjacent items that are in the wrong order. After one full pass, the largest unsorted value is in its final place.

Each pass can ignore one more item at the end — those green bars are already sorted.

TipEasy to understand, but slow for large lists (O(n²)). Great for learning swaps and loops.
IdeaNested loops
bubble_sort.pyPython
for pass_i in range(n - 1):
    for j in range(n - 1 - pass_i):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]

Remember

What bubble sort teaches

Adjacent swaps and shrinking unsorted regions.

Pass

One pass locks one item

After pass k, the last k items are sorted and never move again.

Swap

Only neighbours swap

That’s why large values slowly migrate right like bubbles rising.

O(n²)

Quadratic comparisons

Nested loops mean work grows quickly — useful for teaching, rare in production.
