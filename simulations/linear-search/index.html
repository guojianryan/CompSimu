Linear search

Check items one by one from left to right. Simple, reliable — and you can see exactly how many comparisons it takes.

Algorithms Beginner Arrays · Search ~5 min
The idea

Scan until you find it

Linear search walks an array from index 0 to the end. At each position it asks: “Is this the value I’m looking for?”

If yes — stop. If no — move to the next index. Worst case you check every element; best case you find it first.

TipWorks on unsorted data. Binary search needs sorted data; linear search does not.

Remember

When to use linear search

It’s the right tool when the list is small or unsorted.

O(n)

Time grows with size

In the worst case you look at every element once — fine for short lists, slow for huge ones.

No prep

No sorting required

Unlike binary search, the array can be in any order.

Early exit

Stop when found

You don’t keep scanning after a match — that saves work on average.
