Totalling a 2D array

Keep a running total while you visit cells — across the whole grid, one row, or one column.

Programming Beginner 2D arrays · Accumulators ~6 min
The idea

Same accumulator, new shape

Just like a 1D sum: start at 0, then add each visited value. The only change is which cells you visit — all, one row, or one column.

TipWatch the total box jump after every add — that is the accumulator updating.
