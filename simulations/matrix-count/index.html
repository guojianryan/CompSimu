Counting in a 2D array

Count a target across the whole grid, or build a list of counts — one per row, or one per column.

Programming Beginner 2D arrays · Counters ~7 min
The idea

One count — or a count for each line

A single count can scan the whole matrix. To get every row count (or every column count), reset the counter for each line and append the result to a list.

TipGreen cells are matches. Blue is the cell being checked right now.
IdeaCount matches

row_counts = []
for r in range(rows):
    count = 0
    for c in range(cols):
        if grid[r][c] == target:
            count = count + 1
    row_counts.append(count)
