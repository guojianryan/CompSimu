Counting in a 2D array

Scan the grid for a target value. Count matches in the whole matrix, a single row, or a single column.

Programming Beginner 2D arrays · Counters ~6 min
The idea

Compare, then maybe add one

Start count at 0. Visit each cell in the chosen region. If grid[r][c] == target, add 1.

TipGreen cells are matches. Blue is the cell being checked right now.
IdeaCount matches
matrix_count.pyPython
count = 0
for r in range(rows):
    for c in range(cols):
        if grid[r][c] == target:
            count = count + 1
