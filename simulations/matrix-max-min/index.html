Max & min in a 2D array

Seed from the first cell you visit, then update max_val and min_val as you scan the region.

Programming Beginner 2D arrays · Comparisons ~7 min
The idea

Track the extremes

Start both max and min from the first visited cell. For every later cell, ask: bigger than max? smaller than min?

TipGreen highlight marks the current max; mint marks the current min.
IdeaSeed then scan
matrix_max_min.pyPython
max_val = grid[0][0]
min_val = grid[0][0]
for r in range(rows):
    for c in range(cols):
        if grid[r][c] > max_val: max_val = grid[r][c]
        if grid[r][c] < min_val: min_val = grid[r][c]
